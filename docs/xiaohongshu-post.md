## 笔记 2:技术种草型

### 标题
- 程序员写工具自救实录:Lottie 压缩 100×
- 这个小工具救了我一整个下午

### 正文

家人们谁懂啊,周五下班前接到一个 71MB 的 Lottie 文件 😭

设计师还说"就一个小动画"。

要不是我自己写了个压缩工具,这个周末我得通宵改方案。

工具地址:lottie-mini.com

为什么 Lottie 会这么大?因为设计师在 AE 里用了 PNG 帧序列,这些 PNG 会被 base64 编码塞进 JSON 里——一个动画可能内嵌几百张 PNG。

工具做的事:
1️⃣ 解析 JSON 找出所有内嵌图片
2️⃣ PNG → WebP 重编码(同画质体积省 80%)
3️⃣ 按目标帧率抽帧 + 重写时间轴
4️⃣ 输出新的 Lottie

最爽的是 100% 本地跑,公司机密文件随便压,不怕泄露。
